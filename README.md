# Bluetoothify a Wired-Barcode Scanner

I wanna take a salvaged or any usb-wired barcode scanner and use an esp32 to add bluetooth feature. 

My goals include: 

- Use a cheap ali-express UHS mini to give usb connection without using the usb-c
- Use the esp32-s3-zero to take in barcode scanned data and relay it to a phone or other device through bluetooth. 
- Create a PCB-form factor that can be considered industry level
- Create a consumer approved enclosure that is both nice and functional
